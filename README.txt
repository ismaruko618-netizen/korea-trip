2026 韓國歲修 — iPhone 安裝說明
==============================

這是一個「加入主畫面」的網頁 App，不需要登入任何帳號，也不需要 App Store。

【步驟】
1. 把這個資料夾放到一個 https 網站空間。最簡單：
   - 打開 https://app.netlify.com/drop ，把整個資料夾拖進去，就會得到一個網址。
   - 也可以用 GitHub Pages 或 Cloudflare Pages。
2. 用 iPhone 的 Safari 打開那個網址。
3. 點下方「分享」→「加入主畫面」。桌面就會出現「韓國歲修」圖示。
4. 第一次需要有網路。之後行程、記帳、行李清單沒網路也能看。

【翻譯】
- 文字與對話翻譯：使用公開的免費翻譯服務，不用登入、不用金鑰，但需要手機有網路。
- 圖片翻譯：先在手機上辨識照片文字，再翻成中文。第一次使用要下載辨識模型（約十幾 MB），
  之後會存在手機裡。手寫字或花俏字體的準確度有限。
- 常用韓文句子與朗讀不用網路。

【注意】
- 每支手機的修改和記帳只存在自己的手機，不會同步給別人，也沒有「只有你能修改」的限制。
- 想把行程傳給旅伴：請把整個資料夾的網址給她們，她們看到的是出發時的預設行程。
